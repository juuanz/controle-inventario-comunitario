# Sistema de Controle de Inventário e Empréstimos Comunitários

Projeto Integrador da disciplina Laboratório de Programação.

## Sobre o projeto

O projeto desenvolve um sistema em Python para auxiliar uma comunidade no
controle de ferramentas, equipamentos e outros itens compartilhados.

O sistema permite cadastrar itens e usuários, registrar empréstimos, consultar
a disponibilidade dos itens, executar buscas, ordenar registros e gerar um
ranking e um relatório.

## Problema

O compartilhamento de itens sem um controle organizado dificulta saber quais
objetos estão disponíveis, quem está responsável por cada empréstimo e quando
uma devolução deve ocorrer. Isso pode provocar atrasos, perdas e conflitos entre
os usuários.

## Objetivo geral

Desenvolver um sistema em Python para auxiliar o controle do inventário e dos
empréstimos de itens comunitários, permitindo cadastrar, consultar e acompanhar
a utilização dos objetos compartilhados.

## Funcionalidades atuais

- Cadastro e consulta de itens;
- cadastro e listagem de usuários;
- registro e listagem de empréstimos;
- busca sequencial e busca binária;
- ordenação por inserção;
- ranking dos itens mais emprestados;
- relatório com totais e média de empréstimos;
- persistência dos dados em arquivo JSON;
- execução pelo terminal.

## Funcionalidades futuras

- Registrar devoluções pelo menu;
- criar uma fila de reservas;
- remover itens, usuários e empréstimos;
- tratar arquivo de dados ausente ou inválido;
- criar uma interface visual.

## Tecnologias

- Python;
- JSON;
- Git e GitHub.
