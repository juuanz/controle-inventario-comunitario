# Sistema de Controle de Inventario e Emprestimos Comunitarios

Projeto Integrador da disciplina Laboratorio de Programacao.

## Sobre o projeto

O projeto propoe o desenvolvimento de um sistema em Python para auxiliar uma
comunidade no controle de ferramentas, equipamentos e outros itens
compartilhados.

O sistema devera permitir o acompanhamento do inventario, da disponibilidade
dos itens, dos emprestimos, das devolucoes e das reservas.

## Problema

O compartilhamento de itens sem um controle organizado dificulta saber quais
objetos estao disponiveis, quem esta responsavel por cada emprestimo e quando
uma devolucao deve ocorrer. Isso pode provocar atrasos, perdas e conflitos entre
os usuarios.

## Objetivo geral

Desenvolver um sistema em Python para auxiliar o controle do inventario e dos
emprestimos de itens comunitarios, permitindo acompanhar sua disponibilidade,
retirada, devolucao e reserva.

## Escopo inicial

- Cadastro e consulta de itens;
- cadastro de usuarios;
- registro de emprestimos e devolucoes;
- fila de reservas;
- pesquisa e ordenacao de itens;
- persistencia dos dados em arquivos JSON;
- relatorios e estatisticas simples;
- execucao pelo terminal.

## Tecnologias

- Python;
- JSON;
- Git e GitHub.

## Situacao

Projeto em fase de analise e definicao dos requisitos.
